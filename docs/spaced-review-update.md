# 到期复习与今日任务

完成日期：2026-10-11。对应候选功能 3，沿用 [更新候选中的 10 项核心验收清单](update-candidates-2026-10-10.md#3-到期复习队列与今日任务)，每项权重 10。范围为本地间隔复习、评级、历史及参数管理。

## 入口与日常使用

- **小题狂练 → 到期复习**：今日队列、管理卡片、复习历史、调度设置。小题狂练名称保持不变。
- **首页 → 今日待办**：自动生成一项复习任务，显示剩余、已复习和限额外项目；点击直接进入队列。
- **桌宠 → 今日待办**：同样显示复习任务；点击会恢复学习台并打开到期复习。主窗口操作后广播刷新，其他窗口还会每 15 秒同步。
- **题目解析 → 加入复习计划**：可手动加入选择题或主观题。知识点阅读中也有独立的加入按钮，以当时的解析摘录生成短知识卡。
- 默认将新发生的选择题错答、主观题确认未掌握项加入计划；可关闭。老错题通过“导入现有错题”加入。重复加入不会重置记忆进度；暂停卡不会被再次答错偷偷恢复。

先独立回忆，可以在文本框暂存作答或在纸上作答。点击“完成回忆，查看参考解”后展示参考答案、相关解析/图解和四档评级的预计间隔。完全不会选“忘记”，仍能回忆但吃力选“困难”，犹豫后记得选“良好”，轻松回忆选“轻松”。系统不把答对自动转成 Good。

使用提示要勾选记录；同一次调度已展开过参考解、又重新进入时，也会提示已看答案。评级历史保存实际回忆内容与提示标记。回忆草稿暂存在该浏览器；评级后的内容保存在 SQLite 中。

## 数据与调度规则

- 新增 `scheduled_review_items`、`review_events`、配置/展示令牌/优化任务表；原导入审核的 `review_items` 和 API 保留。
- 首次迁移已有库前，SQLite backup API 生成 `backend/data/backups/*-before-reviews-v1-*.sqlite3`；测试实际打开备份验证旧数据可读。
- UTC 保存时间；默认 `Asia/Shanghai`，支持 IANA 时区和夏令时。待办 ID 由时区与日期派生，反复打开不会重复写手动待办。
- 每日额度按当日首次评级的不同卡片计数，不按点击次数计数。已开始的学习/重学步骤继续进行；稍后到期仍计入今日剩余。限额外项目明确显示。
- 评级采用事务、卡片 revision、已展开参考解的令牌、幂等请求 ID；多窗口旧状态会被拒绝并要求刷新。
- 原题与参考解保存加入时的文字快照；图片按快照的来源/区域预览，原始文件仍需保留。题面接口不返回答案、图解或采分点。
- 撤销只针对最近一条有效评级，保留审计记录；如果该卡已发生其他管理操作，会拒绝撤销，防止覆盖新状态。
- 修改参数只影响之后的评级；“按已保存参数重排”才会更新既有卡片。重排保留暂停与暂缓；恢复默认保留历史、时区、提醒与自动加错题的偏好。

## 优化器与安装

运行 `setup.bat` 或 `start.bat` 会补齐新增依赖：`fsrs[optimizer]==6.3.2`、`tzdata==2026.5`，以及固定的 torch / numpy / pandas / tqdm。首次下载会比之前大，已在本机项目虚拟环境完整安装并通过 `pip check`。无需 Agent 或 API Key，也不会上传复习记录。

当前官方优化器仅在至少 **512 条有效跨日记录**时训练；每张卡最多使用前 64 次评级。少于门槛时保留默认参数，不显示“已优化”。包含提示的卡片整条历史不参与训练，避免截断历史或把辅助回忆当成独立表现。

训练在后台进行，产生候选参数后需点击应用。训练期间历史或配置改变会使候选过期，需要重新训练，防止覆盖新数据。应用重启中断的训练会标记为中断，可重试。保留率由用户配置；没有加入基于复习时长模拟的自动保留率推荐，它不在本次约定的参数优化验收项内。
