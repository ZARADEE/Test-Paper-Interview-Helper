# 番茄钟延伸设计：桌面计时、到点提醒、超时与答案册

日期：2026-10-14。状态：已按本稿实施，静态审阅与运行检查记录见[实现与验收记录](pomodoro-ambient-timer-implementation-2026-10-14.md)。本文保留设计依据；最终入口、尺寸和验证边界以实现记录为准。

目标：延伸现有番茄钟，让日常专注、限时做题和整卷计时共用一套操作。开始后可以留在学习台，也可以进入桌宠或悬浮球；到点提醒，同时开始记录超时；用户明确结束后结算。

## 2. 用户只需记住的规则

1. 一个应用同时只有一轮计时，学习台、桌宠、悬浮球显示同一轮。
2. “到点”表示计划时间用完；“结束本次”才表示本轮停止。
3. 到点立即进入超时，不需要点击继续；收起提醒不结束、不暂停、不归零。
4. 暂停只在到点前可用；进入超时后一直计时，直到明确结束。
5. 切页面、关主窗口进入桌宠、切换桌宠/球，只改变显示形态。
6. 开始下一轮、开始休息、修改目标都由用户主动发起。

产品名称仍为“番茄钟”。本稿把“闹钟”理解为本轮到点提醒及声音开关；不增加独立的闹钟列表。试卷计时是一条设置本次名称与时长的快捷路径。

## 3. 开始计时

### 首页

- 保留专注、短休、长休及分钟输入；时长范围统一为 1–1440 分钟，覆盖现有试卷模板范围。专注可以设为 180 分钟。
- 可选填写“本次名称”，默认使用模式名称，例如“408 模拟卷 03”。
- 主按钮“开始”留在当前页面；旁边下拉提供“开始并进入桌宠 / 开始并进入悬浮球”，不让普通开始突然隐藏窗口。
- 提供“到点提示音”、音量与试听，默认开启、适中音量；视觉提醒始终保留。偏好持久化。
- 开始前可改模式与时长；开始后本轮目标固定，暂停中也不能通过改时长清空进度。
- 进行中再次请求开始，显示“已有一轮正在计时”，提供“查看当前计时”；先结束当前轮，再开新轮。

### 组卷页

新增“用本卷时长计时”，在当前页展开准备区，显示卷名和模板时长；用户可在开始前修改。点击入口只准备，不立即计时。取消不改变首页设置，本次 180 分钟也不覆盖日常 25 分钟默认值。

```text
本次：408 综合模拟卷 03
时长：180 分钟             到点提示音：开
[开始计时 ▾]               [取消]
  留在学习台 / 进入桌宠 / 进入悬浮球
```

用户可以先下载或打印题卷、准备纸笔，再开始。结束计时不等于交卷、判分、答题完成或勾选任务。

## 4. 桌面计时的外观与操作

### 4.1 常驻计时条

桌宠上方或球旁显示独立计时条；两种形态操作一致。初始建议约 208 × 76 DIP，最终按文字、长时间和实际缩放验证尺寸。

```text
┌──────────────────────────┐
│ 专注 · 剩余      闹钟：开  │
│ 24:18    预计 15:30 到点   │
└──────────────────────────┘
         桌宠 / 悬浮球
```

- 点击时间区域展开控制；闹钟按钮可开关声音，不改变计时。
- 名称过长可省略，展开后读全。数字等宽、固定预留宽度，避免每秒跳动。
- 不足一小时显示 MM:SS，达到一小时显示 H:MM:SS；超时用“已超时 +02:17”，不用负数倒计时。
- 暂停显示“已暂停”和固定剩余；暂停时隐藏预计到点，恢复后重算。
- 预计到点跨日时标注“明日”或完整日期，不能只显示一个易误解的时分。未开始时不显示空计时条；结束后可收起结算卡，桌面恢复原状，首页仍可查看最近结果。
- 超时后的常驻条保留可直接点击的“结束本次”，无需层层找菜单。

### 4.2 控制面板

```text
┌──────────────────────────────┐
│ 408 综合模拟卷 03      [收起] │
│ 剩余  1:42:08                │
│ 计划 180 分钟 · 17:00 到点   │
│ [暂停]          [提前结束]   │
└──────────────────────────────┘
```

- 运行中：“暂停 / 提前结束”；暂停后：“继续 / 提前结束”。
- 提前结束在面板内确认“现在结束并保存本次用时？”；直到确认才停止，取消维持原状态。
- 已到点：“结束本次 / 收起提醒”；结束直接结算，不再多问一次。
- 提前结束确认期间如果刚好到点，仍按实际截止进入超时；确认文案同步为“结束本次”，最终按确认时刻结算，不伪记为提前结束。
- Esc、收起按钮、点击外部只收起面板，保留计时条；不会结束或暂停。
- 展示区没有一个含义不清的“关闭”按钮同时承担关面板与停计时。

### 4.3 位置、漫游与已有操作

- 优先贴在角色上方，其次下方或屏幕内部一侧；保持上一次可用方位，避免不断跳边。
- 按角色和计时条的联合区域避让工作区边缘、任务栏、待办面板和菜单；必要时轻移整组。空间不足时收起展开面板，至少保留可操作计时条。
- 拖动角色或计时条标题区可以移动整组；按钮操作不触发拖动，拖动结束抑制点击。
- 整轮计时期间临时停止桌宠自动漫游，包括暂停和超时阶段；仍可手动拖动。原漫游偏好不改，结束结算卡收起后恢复。
- 单击桌宠仍为互动与待办、双击仍开学习台；单击球仍开学习台。计时条独立响应，不抢这些动作。
- 待办和计时可同时打开，关闭待办不影响计时；计时不被做成一条可勾选待办。
- 回到学习台时隐藏桌面计时条；应用内换页可见小型计时状态入口，点击返回番茄钟。首页完整番茄钟可见时不重复显示小条。
- 角色窗口保持原定尺寸，计时附属窗口独立布局，避免扩大透明窗口挡住其他应用。

## 5. 到点、提醒和超时

计划时间用完的同一时刻，发出到点事件并从 +00:00 开始超时。提醒是否展示成功、用户是否看到，都不改变超时起点。

```text
┌────────────────────────────────┐
│ 时间到了                       │
│ 已超时  +02:17                 │
│ 计划 25:00 · 当前用时 27:17    │
│ [结束本次]      [收起提醒]     │
│ 收起后仍会继续记录超时。        │
└────────────────────────────────┘
```

### 提醒方式

- 一段约 3 秒的本地提示音，默认适中音量；不循环轰炸，不每分钟重弹。用户静音时只有视觉提示。
- 计时区域变暖橙色并写“已超时”；最多两次低频强调，减少动态效果时仅静态变色。
- 桌宠/球可见时面板原位展开，不拉起学习台、不抢输入焦点；用户不操作也持续超时。
- 学习台在前台时在当前可见位置提醒；不要求切到首页，应用内小条可原位展开。
- 学习台不在前台、也没有可见桌面计时条时，可补一条系统通知。通知自身静音，提示音只有一份；点击通知打开当前计时，关闭通知不结束。
- 多窗口共享一次到点事件和一次播放权，切换窗口不重复响。
- “收起提醒”停止尚在播放的提示音并收起面板；不是稍后提醒，不修改截止、不延长目标、不重开一轮。
- 关闭闹钟声音只静音并保存偏好；关闭系统通知仅关闭通知，本地短提示音自行结束。两者都不结束计时。
- “结束本次”立即停音并冻结用时，保存结算。

## 6. 状态与时间计算

| 状态 | 展示 | 操作 | 转移条件 |
|---|---|---|---|
| 未开始 | 名称、计划时长 | 改设置、开始 | 点击开始 |
| 计时中 | 剩余、预计到点 | 暂停、提前结束、切形态 | 暂停 / 确认结束 / 到点 |
| 已暂停 | 固定剩余、暂停标识 | 继续、提前结束、切形态 | 继续 / 确认结束 |
| 已超时 | 正向超时、计划与用时 | 结束、收起、静音、切形态 | 仅明确结束本次 |
| 已结束 | 本轮结算 | 收起、再来一轮、开始休息、查看本卷 | 主动开下一轮 |

到点前暂停会冻结用时，继续后到点时间相应顺延。超时后不提供暂停，额外做题时间持续记录。临界操作先结算当前时间再判断：如果已到点，暂停请求提示“已到点，请结束本次或继续记录超时”。

专注、短休、长休均采用到点后手动结束规则；休息超时写“休息已超时”。整卷训练可自行保持不暂停；暂停过则在结算如实显示。

### 口径

- 计划时长 P：开始前确认，开始后冻结。
- 计时用时 E：开始至结束的经过时间，扣除用户明确暂停的时段。锁屏、休眠、退出期间不会自动当暂停；它不被宣传为全部有效学习时间。
- 剩余 = max(P − E, 0)；超时 = max(E − P, 0)。
- 正常时钟条件下，总经过时间 = 计时用时 + 暂停时长。
- 提前结束为 E < P；达到计划为 E ≥ P。毫秒计算、显示到秒：剩余向上取整，超时向下取整，状态不依赖格式化数字。
- 本轮模式与目标固定；移除运行中切模式即重置的行为。“重置”仅重置未开始的准备设置，不清除活动计时或结算记录。

### 结算

```text
本次已结束 · 408 模拟卷 03
计划 3:00:00    计时用时 3:02:17
超时   02:17    暂停     00:00
[查看本卷] [再来一轮] [开始短休] [收起]
```

- 记录名称、计划、用时、暂停、超时或提前结束；起止时刻及总经过时间可展开查看。有试卷关联才显示查看本卷。
- 本地保存结算，首页保留最近一轮摘要，不增加独立统计大面板。结束不勾选待办、不改成绩。
- 专注达到计划且用户明确结束才计为完成一轮；180 分钟也只是一轮。提前结束、短休、长休不增加专注轮数，原累计轮数保留。
- “再来一轮”明确开始相同设置的新一轮；“开始短休”主动开启短休；结束本身不自动开始下一轮。
- 双击结束、多窗口同时操作、IPC 重试只保存一份结果、加一次轮数；旧窗口迟到的指令不能结束下一轮。

## 7. 切换与恢复

| 情况 | 行为 |
|---|---|
| 关主窗口进入桌宠、切球、换角色/大小 | 同一会话继续，仅重排显示 |
| 回学习台或切应用页面 | 时间同步，不重置，不重发到点声音 |
| 暂停后退出重启 | 保持暂停，不补算为用时 |
| 锁屏、休眠后唤醒 | 运行轮按经过时间补算；跨过截止显示真实超时，最多补发一次尚未发出的提醒 |
| 彻底退出后再启动 | 恢复未结束轮；运行轮包含关闭期间用时，暂停轮保持暂停；显示恢复说明，不猜测结束时刻 |
| 退出期间到点 | 应用未运行不能响铃；下次启动显示超时，最多补发一次尚未记录的提醒 |
| 已响过再启动 | 保留超时，不再响铃；仍需明确结束 |
| 声音或通知不可用 | 视觉提示、超时、结束照常，设置中有可理解的状态说明 |
| 后端不可用 | 本地计时继续，试卷下载失败单独提示 |
| 跨屏、负坐标、缩放不同、拔掉屏幕 | 整组回到可用工作区，时间和结束按钮可见 |

彻底退出入口提示“退出后无法提醒；未结束计时下次打开会恢复”，与关闭主窗口进入桌宠区分。产品不主动阻止系统休眠；电脑休眠或应用不运行时不承诺准点出声。

同进程使用单调经过时间，配合休眠恢复处理，避免修改系统时钟使倒计时突跳；时区只影响本地预计到点显示。跨进程依赖保存时间戳，检测到时钟倒退等矛盾时标明“系统时间变化，本次需要核对”，保留原记录，允许从最后可靠用时继续或结束并标注异常；不虚构精确用时。无法检测的关机期间时钟修改不承诺准确恢复。

## 8. 题卷与答案册成套交付

### 入口

组卷结果的主导出操作为“导出题卷 + 答案册”，下拉选择 PDF / Word，默认 PDF；保留“单独导出”，旁边是“用本卷时长计时”。一个 ZIP 包含两份同格式文件，减少连续下载操作并便于保存。

```text
408综合模拟卷03_题卷.pdf
408综合模拟卷03_答案册.pdf
```

下载不自动打开答案；开始、超时、结束也不擅自展示答案。用户仍可主动单独获取答案，不加考试锁。

### 内容与一致性

- 题卷含题目与必要说明，不泄露答案。答案册沿用当前含题面对照的答案版，显示可用参考答案、解析和评分点，不声称全部经过官方核验。
- 两册清晰标注“题卷 / 参考答案与解析”、相同卷名、卷号/导出版本、总分与计划时长；题号、顺序和分区一一对应。
- 同一次成套导出冻结题面、答案、分区、分值、模板时长及素材版本；两份文件共用同一快照。导出时编辑原题不能造成两册不一致，重试使用同一版本。
- 修改内容后导出新版本，不覆盖旧版本配套关系；从已导出卷发起计时，关联其版本及模板时长。未导出时至少保存名称、paper_id 与时长快照。
- 答案、解析、图片缺失要区分，答案图本身算有效内容，不因无文字答案误报。导出前显示受影响题号，答案册同步列缺失项，不生成虚构答案。
- 内容不全时可选“继续导出并标注缺失 / 返回检查”；结构错误或文件损坏不得报成套成功。
- 两份文件都生成、校验成功才发布 ZIP；一份失败就显示明确原因和重试，不能把只有题卷的包标成整套。

复用现有题卷/答案版生成器，增加组合入口、元数据和一致性保护，不扩成在线交卷和阅卷。

## 9. 工程落点与兼容

### 单一计时来源

桌面端将计时所有权从 HomeDashboard 的 React 状态移至 Electron 主进程 TimerService。窗口订阅快照、发送命令；每秒刷新只负责显示，不依赖回调执行次数累计时间。

保存 schemaVersion、sessionId、revision、mode、title、plannedMs、status、起止与运行时间基准、累计用时、暂停记录、到点事件标记、声音偏好、结算和可选试卷版本。计时状态与提醒面板的展开/收起相互独立。

- 开始、暂停、继续、结束串行执行；指令携带 sessionId/revision/requestId，校验来源窗口、目标会话及合法状态。
- 状态保存在 Electron 用户目录独立文件，原子替换；状态改变立即保存，运行中有检查点。保存失败明确显示“本次尚未保存”，不假报成功。
- 主进程负责到点和播放授权；一个专用声音承载播放，重建时不重复领同一提醒事件。记录提醒状态后再播放，崩溃极端情况下优先避免重复响；视觉超时始终可恢复。
- timerWindow 复用既有轻量窗口模式，独立控制 showInactive、布局、可点击区域和角色联合边界；不要直接照搬待办的 15 秒轮询来做计时。
- 结束先确定并保存结果，再广播；重复请求返回已有结果，不创造第二份。

### 迁移与浏览器

- 首次读取旧 pomodoro.v2 和时长偏好，保留累计轮数与旧记录备份；成功写入新状态后才设置迁移标记，避免每个窗口重复导入。
- 旧计时仍运行，可由 remainingSeconds/updatedAt 恢复，已跨过目标则超时；原数据没有完整起止和暂停历史，标记“从旧计时恢复”，不伪造历史。
- 旧计时已停止且归零按旧版已到点处理，不追溯虚构超时；旧暂停轮继续暂停。
- 浏览器版复用状态机，提供首页计时、超时、声音、结算；多标签页只有一个写入者和提醒者，接管带会话版本防重复。
- 浏览器不显示无效的独立桌宠/球操作；关闭全部标签页无法后台响铃，下次打开按保存状态恢复。

## 10. 视觉与文案

设计原则：把时间做成桌宠旁的一张清晰计时便签，用现有硬边框、平面色块、直接操作表达状态。沿用 new-brutalist-ai-ui 技能；角色和悬浮球保留原形状，不因便签风格而改成方块。

- 运行使用既有中性色和强调色；暂停灰底加文字；超时暖橙加“已超时”；结束中性结果卡。不能只靠颜色区分。
- 不加玻璃模糊、渐变光晕、持续摇晃。时间和结束操作优先。
- 次要文字 12–14px 起、数字约 24–28px；点击目标至少 32 DIP，主要按钮适当更大，最终按长名称与双屏缩放测试。
- 文案固定为开始、暂停、继续、提前结束、结束本次、收起提醒，避免同一词有多种结果。
- 自动提醒不抢焦点，主动展开可键盘操作；读屏只在状态改变时播报，不每秒打断。

## 11. 固定验收场景

1. 开始后桌宠 → 球 → 学习台 → 其他页面，sessionId 相同，时间连续，不重复开一轮。
2. 主窗口隐藏也能到点；0 时立刻超时，过 2:17 显示 +02:17，不停在零。
3. 不理提醒、收起、Esc、关闭系统通知都继续超时；只有结束才冻结。
4. 25 分钟计划，超时 2:17 后结束：计划 25:00、用时 27:17、超时 02:17，之后不再增长。
5. 暂停 5 分钟再继续：目标不变、截止顺延、结算列暂停；超时后没有暂停按钮。
6. 临界到点与暂停/结束并发、重复点击、多窗口旧命令：只结算一次、不误操作下一轮。
7. 未结束时改模式、时长、重复开始或从另一张卷开始，不能无声覆盖。
8. 静音、通知被屏蔽、播放失败：视觉提醒及结束仍可用，不出现多个窗口同时响铃。
9. 到点不抢输入焦点；计时按钮不误开待办、互动或拖动；球与桌宠原点击习惯保留。
10. 漫游临时暂停、拖动整组、四边/角落、100%/150% 双屏、拔屏：尺寸稳定、数字与按钮不裁切。
11. 待办与计时同开可操作，关闭一个不改变另一个或计时。
12. 休眠跨截止后补算并最多补发一次；已提醒过重启不再响。
13. 运行/暂停分别重启、迁移旧状态、保存失败、系统时间异常按规则恢复，记录不被静默清空。
14. 组卷 180 分钟可用；取消准备不改变旧设置；不覆盖日常 25 分钟默认；结束不自动开答案或改成绩。
15. 到点但未结束不增加完成轮数；结束只加一次；提前结束、休息不加。
16. PDF/Word 成套各有两份文件，同卷号、版本、题号、题序、总分、时长；题卷无答案。
17. 导出时编辑原题、缺答案、缺图、单册失败、重试：快照一致，缺项明确，失败不报整套成功。
18. 浏览器多标签只提醒一次；桌面计时不依赖后端在线。

交付包含状态机与固定时钟测试、隔离用户目录的 Electron 回归、双屏截图、成套导出内容检查。各项实际覆盖、实现调整和未实测的物理场景详见[实现与验收记录](pomodoro-ambient-timer-implementation-2026-10-14.md)，不将本节设计清单等同于全部场景均已实机验证。
