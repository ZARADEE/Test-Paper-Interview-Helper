# 番茄钟延伸与配套答案册：实现及验收

日期：2026-10-14。对应[设计文档](pomodoro-ambient-timer-design-2026-10-14.md)。已完成代码实现、静态审阅、构建、自动化回归和真实 Electron 窗口检查。

## 1. 使用方式与交互规则

首页番茄钟设置名称、模式、时长和提示音后，选择留在学习台、进入桌宠或进入悬浮球，再点击“开始计时”。三种显示形态共用同一轮计时。专注、短休、长休各自保留默认时长，本次输入只有点击“设为此模式默认时长”才会成为默认值。

| 状态 | 显示与操作 |
| --- | --- |
| 进行中 | 剩余时间、计划时长与预计到点时间；可暂停或提前结束 |
| 暂停 | 剩余时间固定，隐藏预计到点；可继续或提前结束 |
| 到点/超时 | 暖橙色“已超时 +MM:SS”；一次短提示音；继续累计，不自动进入休息 |
| 收起提醒 | 停止当前提示音，保留常驻计时条，超时仍增长 |
| 结束 | 冻结本次用时，展示计划、实际用时、暂停、超时与起止时间；下一轮由用户发起 |

- 提前结束需在面板内确认；已到点直接结束。结束不等于交卷、判分或完成待办，不会自动展示答案。
- 超时后不提供暂停；到点但没有结束不增加完成轮数，达到计划的专注轮在结束时仅计一次。
- 计时条位于桌宠或球附近。常驻宽度 266 DIP，展开宽度 330 DIP；按屏幕可用高度滚动，保留结束入口。超过一小时显示 H:MM:SS。
- 拖动角色或计时条标题移动整组；布局避让工作区边缘和待办。角色原有大小、单击、双击、右键入口保持原意。
- 本轮及桌面结算卡可见期间临时停止自动漫游；收起结算后恢复原漫游偏好。
- 到点展开不抢输入焦点，不拉起学习台；声音默认开启，可调音量、试听或静音。使用本地 3 秒音频，不循环播放。
- 切回学习台隐藏桌面计时条；在其他页或首页番茄钟滚出可视区时，显示应用内小条。

## 2. 用试卷时长计时与成套导出

组卷结果提供“整套 PDF（ZIP）”“整套 Word（ZIP）”。ZIP 内分别是题卷和答案册，文件名明确区分。答案册沿用题面对照，包含已有参考答案、解析和评分点；不会生成缺失答案。

成套导出先冻结题序、题面、答案、分区、每题分值、模板总分/时长与实际图片，再用同一快照生成两册。两册均带卷号、版本、总分和时长；题卷不输出答案。任一册生成或校验失败，整套任务失败且不能下载残缺包，重试仍使用原版本。

答案、文字解析、原版题面或解析图缺失时，导出前列出受影响题号，用户可明确选择继续并标注缺失，或返回检查。有效答案图片不因缺少文字答案而被误报为空。损坏图片、题目缺失、重复或结构错误会阻止成套发布。

“用本卷时长计时”先展开准备区，默认采用这张卷的模板时长，可修改名称和本次时长。确认前不开始；取消不改日常默认。已经导出的卷关联具体版本，“查看本卷”读取该快照。重新下载或切换文件格式保持该版本内容，不因后台编辑原题而悄悄换卷。需要采用新的题库内容时重新组卷。

“单独导出”保留原有入口并提示读取当前题库内容；它没有成套版本保证，配套使用应优先选择整套导出。

## 3. 状态、保存与恢复

- 桌面端由 Electron 主进程 TimerService 持有唯一状态，页面只订阅快照、发送命令。命令检查 sessionId、revision、requestId，拒绝旧窗口操作新一轮，重复结束不重复结算。
- 同进程采用单调经过时间；系统休眠/恢复和应用重启按保存的时间戳补算。暂停期间只增加暂停时长。检测到时间倒退时显示异常并允许从可靠用时继续，原记录保留。
- 状态文件为 Electron 用户目录的 focus-timer.json；操作立即保存，运行中定期写检查点，通过临时文件替换并保留 .bak。保存失败明确提示并回滚未成功的操作；损坏原文件保留，不悄悄清空历史。
- 首次迁移旧 pomodoro.v2 与各模式时长，保留旧存储作为备份。旧版已停止归零不虚构超时；旧暂停状态继续暂停。
- 浏览器版复用状态机，以 Web Locks 串行协调标签页、以本地存储同步，只有一个标签页领取到点提示。关闭一个标签页可由其他标签页继续；全部关闭期间无法出声，重新打开后补算。
- 完全退出应用后不能后台提醒；关闭学习台进入桌宠与彻底退出是不同操作。计时本身不依赖后端在线。

## 4. 静态审阅与修正

审阅覆盖状态机、主进程 IPC/持久化、跨窗口显示、声音授权、试卷联动和成套导出。审阅及运行检查中发现并修复：

1. 旧轮次的重复结束命令可能停止新轮提示音：仅对实际生效的状态变更停止声音，并添加服务回归。
2. 多标签页对结束/静音状态的常规同步可能中断主动试听：仅在状态转换时停止声音，并添加双窗口试听回归。
3. 靠近待办时只避让计时窗、角色仍可能遮挡待办：改为检查整组，并在桌面验收中强制放置于冲突位置。
4. 已导出版本再次导出可能读取实时题库：显式携带来源版本，复用冻结内容；测试先修改原题再验证导出内容不变。
5. 使用解析图片时评分点可能被跳过，单题分值也缺少明确标注：两册补充分值，答案册独立输出评分点，检查真实 Word 内容。
6. 从计时结果查看本卷时左侧组卷参数可能仍显示另一张卷：加载快照时同步卷名、模板与种子。
7. 全局按钮阴影影响计时数字边缘、主窗口指标挤压：调整局部样式，并复核最终截图。

### 复现命令

项目根目录运行后端检查；脚本将临时数据限制在项目内：

```powershell
.venv/Scripts/python.exe -B scripts/check_timer_backend.py
.venv/Scripts/python.exe -B scripts/timer_smoke_server.py
```

第二条命令启动 127.0.0.1:8017 隔离数据服务，供桌面和浏览器运行检查使用；另开终端，在 frontend 目录运行：

```powershell
npm run build
npm run test:timer
node --test pet-physics.test.mjs
npm run smoke:timer
npm run smoke:timer-browser
npm run smoke:pet
```

完成后用 Ctrl+C 结束隔离服务。自动化使用项目内临时数据库、用户目录与导出目录；桌面运行会短暂显示测试窗口。没有以正式用户计时记录或正式数据库执行写入验收。

## 6. 实现调整与验证边界

- 成套 PDF/Word 采用两个明确按钮，计时形态采用下拉选择；共享组件放在 TimerCard.tsx，AmbientTimer 从该文件导出，避免两套交互逻辑。
- 提醒采用静态暖橙强调，不加持续动效；常驻/展开实际宽度根据长名称、按钮与双屏截图调整。
- 系统真实休眠、物理拔屏未在本次实机操作；休眠补算、恢复逻辑有固定时钟/服务测试，屏幕事件有静态检查，不能等同于物理场景验证。
- 浏览器运行检查使用 Chromium；其他浏览器未实测。需要支持 Web Locks 的安全上下文；浏览器补算依赖系统时间戳，直接改动系统时钟可能影响恢复精度。桌面同进程采用单调计时。
- 音频已检查真实 Electron 播放调用成功和本地文件 3 秒时长；浏览器多窗口测试以播放调用计数检查单次授权，不代表各浏览器自动播放策略均已验证。
- 磁盘不可写时不承诺崩溃后仍恢复最新用时或绝不补发提示，界面会明确报告未保存；不掩盖故障。
- 构建仍有既有 JSCPP 的 eval 与 printf 的 Node 模块浏览器外部化警告；构建成功，本次未修改这些依赖。
