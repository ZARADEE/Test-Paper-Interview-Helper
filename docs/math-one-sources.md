# 数学一题源与比例策略

## 日期口径

当前日期为 2026 年 8 月 23 日。中文语境中的“2026 考研”通常指 2025 年 12 月举行的初试；当前正在准备的是 2027 考研。项目不会把 2026 年和 2027 年混成同一套数据。

## 题源边界

项目采用三类来源：

1. **公开题源**：接入公开仓库中的数学一 Markdown 真题，默认导入为“待审核”，保留年份、原文件名和来源仓库。
2. **本地资料**：用户选择自己合法取得的 PDF、DOCX 或 DOC，应用只在本机解析并写入本地题库。
3. **人工录入**：补充习题书中的题目、章节、难度和评分点。

商业习题书不通过项目自动下载、破解或重新分发。对于用户已经购买或拥有的资料，使用“试题导入”页处理本地文件即可。

当前公开样本源：

- 仓库：`https://github.com/TsekaLuk/Kaoyan-Math1-Papers`
- 原始文件：`https://raw.githubusercontent.com/TsekaLuk/Kaoyan-Math1-Papers/main/papers/2025年数学一真题.md`
- 许可证：CC BY-NC-SA 4.0

截至当前实现，公开仓库可确认到 2025 年文件，未把网络上无法核实许可的“2026 习题书电子版”写入项目。

## 章节标签

导入器按关键词给题目打两层标签：

- 一级科目：高等数学、线性代数、概率论与数理统计
- 二级章节：函数/极限/连续、一元函数微分学、一元函数积分学、多元函数微分学、重积分与曲线曲面积分、微分方程、无穷级数、行列式与矩阵、向量与线性方程组、特征值/特征向量与二次型、随机事件与概率、随机变量及其分布、多维随机变量、数字特征与大数定律、数理统计

自动分类只用于减少录入工作，分类置信度低或章节为“综合题”的题目必须在审核页确认。

## 初始组卷比例

考研数学一模板使用可编辑的初始结构：

- 选择题：10 题，每题 5 分
- 填空题：6 题，每题 5 分
- 解答题：6 题，共 70 分
- 一级科目分布：高等数学 60%、线性代数 20%、概率论与数理统计 20%

一级比例用于首版组卷约束，不代表每年每个二级章节固定不变。导入更多已审核真题后，应在模板页按统计结果调整二级章节比例。

## 导入命令

抓取公开样本并放入待审核队列：

```powershell
python scripts/import_math_one.py --fetch-public --year 2025
```

导入本机 Markdown 习题或真题：

```powershell
python scripts/import_math_one.py --source-dir "D:\path\to\math-one-materials" --year 2026
```

PDF、DOCX、DOC 继续使用应用的“试题导入”页面；导入后在审核队列中确认题型、章节、答案和标签，再允许进入自动组卷。

## 配对导入题目册与解析册

题目册和解析册分开时，可以使用配对导入器：

```powershell
python scripts/import_li_lin_880.py `
  --questions "D:\path\题目分册.pdf" `
  --analysis "D:\path\解析分册.pdf"
```

导入器会把题干册作为主记录，按章节、难度、题型和题号寻找解析册内容。由于扫描 PDF 的文本层可能拆分公式、子问或页眉，解析结果统一进入待审核队列；`backend/data/li-lin-880-import-report.json` 会记录解析数量、配对数量和未匹配数量。
