# 桌面陪伴模式

## 已实现的计划

1. 主窗口关闭后隐藏，自动显示桌宠；可主动切换悬浮球。
2. 透明无边框、置顶、固定窗口大小；拖动只移动，禁止边框缩放。
3. 四套可替换角色：蓝发女仆、纸盒猫、专注机器人、Doro。旧小黄鸭设置自动迁移为 Doro。
4. 保留低频自动动作、点击互动、托盘入口与设置保存，并通过实际 Electron 回归检查。
5. 主进程按实际时间计算二维漫游；按可见素材碰撞盒检测工作区四边、反转对应方向，避开任务栏。

## 操作

- 首页角色卡选择外观，点击“进入桌宠态”或“切换悬浮球”。
- 关闭主窗口后使用上次选择的模式，初次默认桌宠。
- 桌宠 / 悬浮球均可按住左键拖动；拖动结束不会误触打开。
- 单击桌宠播放互动，双击打开学习台；单击悬浮球打开学习台。
- 右键桌宠或系统托盘图标可切换模式、角色、打开学习台或彻底退出。
- 大小只能在首页或右键菜单选择小 / 中 / 大；窗口边缘和普通拖动均不改变大小。
- 首页或右键可开关自动移动；拖动、互动、右键菜单和隐藏时停止位移。
- 位置、角色、模式、大小、自动移动设置写入 Electron 用户数据目录的 desktop-pet.json。
- 隐藏时使用静态帧并停止漫游；重新显示且开启漫游时开始行走，之后穿插待机与特殊动作。

## 动作参数

统一配置位于 frontend/src/petConfig.ts：

| 参数 | 值 |
| --- | --- |
| 待机休息 | 5–9 秒 |
| 待机后动作选择 | 漫游 50%，特殊动作 50%；关闭漫游时只播放特殊动作 |
| 单次漫游 | 6–10 秒 |
| 移动速度目标 | 60 DIP/秒，33ms 更新；浮点坐标累积，固定尺寸 setBounds |
| 特殊动作 | 2.2 秒 |
| 点击动作 | 1.6 秒 |
| 桌宠窗口 | 固定正方形，小 160 / 中 220（默认）/ 大 280 DIP |
| 悬浮球窗口 | 92 × 92 DIP |

角色注册表由主进程、托盘和前端共用。新增角色时在 PET_PACKS 注册，
并在 DesktopPetView.tsx 的 PetArtwork 中提供 idle / walk / special / click
四种状态；素材放在 frontend/public/assets 下，并通过 petAsset 生成地址。

## GitHub 参考与素材

- https://github.com/tonybaloney/vscode-pets
  参考独立角色状态序列和待机、行走、互动的组织方式。本项目调整了状态概率，
  降低漫游频率。历史小黄鸭素材采用该项目的 8 fps 透明 GIF，现已从可选角色中移除。
  资源固定到提交 2c91214beb922288cca1938cddb607abc5f806b7；
  原作者 Marc Duiker，来源及 MIT 声明保存在 public/assets/duck。
- https://github.com/ayangweb/BongoCat
  参考桌面陪伴及多外观的交互形式；没有复制其模型和代码。
- https://github.com/waterfeet/DoroPet
  Doro 来自提交 b0283186889993dcb4284dc5a4b15c5f05719d03 的 Qtpet/doroimg。
  包含趴下、跑动、招手、开心四种动画；来源映射、处理方式和许可证存于 public/assets/doro。
- 蓝发角色沿用已有 WebM 转换出的透明动画；纸盒猫和机器人为本次绘制的 SVG，
  通过独立部件实现眨眼、呼吸、摆尾、挥手和点击反馈。

蓝发和 Doro 素材统一为 256px 透明方形画布，保留动作时间，不再用放大裁剪的视频填充窗口。
生成素材：在 frontend 运行 electron prepare-pet-assets.mjs --no-sandbox，
然后在项目根目录运行 python scripts/normalize-pet-assets.py（需要 Pillow）。
各动作 bounds.json 记录所有帧 alpha 区域的并集；petConfig.ts 的 ART_BOUNDS 对应这些元数据。

## 验证

在 frontend 目录执行 npm run build、node --test pet-physics.test.mjs、npm run smoke:pet。
测试使用独立临时用户数据，不改动现有待办和学习记录。
检查关闭与恢复、透明动画实际帧变化、四套角色、400 次连续拖动、禁止边缘缩放、
工作区四边反弹、跨屏拖动、三档大小、点击与特殊动作、模式切换、拖动抑制点击、隐藏暂停及设置保存。
截图保存在 frontend/out/pet-smoke。

桌宠窗口尺寸测试容许 Windows 分数缩放产生最多 2 DIP 舍入，不允许随移动累积。
已在当前 100% / 150% 缩放的两块显示器上实际验证；纯运动测试另覆盖负坐标、角落、越界和小屏幕。
