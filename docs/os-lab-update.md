## 用户入口与技术方案

小题狂练 → 408 实验台。独立参数模拟与代码练习面板，保持已有练习和复习状态。前端纯函数运行教学模拟，不修改学习数据库。

代码区采用 JSCPP 2.0.9 教学解释器（https://github.com/felixhao28/JSCPP），本地 Worker 执行，提供标准输入/输出、停止、超时、错误反馈与调试。属于 C/C++ 常用语法教学子集，不是原生 GCC/Clang，不生成 exe，不承诺完整 STL、系统调用或多文件支持。系统调用和并发属于确定性模型，不启动真实系统进程。

关键代码解析针对带版本的内置样例；用户改写代码后明确区别样例说明与用户代码，调试数据来自实际执行。

## 使用方式

1. 搜索或选择实验，修改参数，点击“运行实验”。输入错误保留上次有效结果；参数修改但尚未运行时明确提示旧结果。
2. 使用上一步、下一步、最后一步、自动回放、速度和滑块查看状态。CPU、页面、分区、磁盘可进行同参数算法对比。
3. CPU 提供完整甘特图、等待/周转/响应柱图与吞吐量、空闲、切换和利用率；磁盘提供路线图和逐段移动量。
4. C/C++ 区可改源码与 stdin，运行后看 stdout。标准输入需运行前填写，不是运行中实时键盘输入的终端。
5. 逐行调试展示真实执行的下一行和作用域变量；关键代码解析针对内置样例。改写后有明确说明，不把静态讲解误称为任意代码的自动解析。
6. 源码按实验保存在本机 localStorage；载入样例覆盖草稿需确认。标准输入不独立持久化。

CPU 六种调度与页面七种置换均有对应算法代码，点击“载入样例 / 同步输入”可同步当前已运行参数。其他实验使用本主题核心学习样例，如 First Fit、SSTF、银行家安全性、分页；标题明确固定示例，不宣称所有实验都有独立完整 C++ 实现。

## 支持范围与差异

- 常用变量、数组、指针、函数、条件、循环、cin/cout、scanf/printf 可运行；完整 STL、多文件、exe、真实线程和系统调用不支持。无需安装本地编译器或连接在线执行服务。
- Worker 与 UI 分离；单次运行/单步有 4 秒外部截止时间，普通运行另有解释器 2.5 秒限制。源码 32K 字符、stdin 8K、stdout 64K；手动停止、离开代码面板会终止 Worker。
- JSCPP 默认 cstdlib.system 可调用宿主 JavaScript，本次通过可加载头文件白名单禁用 cstdlib、stdlib.h 和示例扩展。该头文件中的 abs/rand 等也不可用，可自行编写简单教学函数。
- C stdio 使用字符串格式器适配，不调用 printf 的 Node stream 重载。已在开发与生产页面实际验证 scanf/printf。
- 同步/系统调用采用确定性状态模型，阻塞操作需显式重试，不自动重排，也不启动真实线程。
- MFT 使用分区列表，等大小列表可表达原固定块；没有“总量 + 块大小”的独立自动换算表单。MVT 可用一个空闲块表达原始单段内存。
- 分页采用整进程装入，帧不足则整体等待；原实现允许部分页面先装入。本次明示原子分配约定。页表查询只报告缺页，不执行完整调页；参考页面同样没有完整调页流程。
- TLB 初始为空，访问后按 LRU 更新；没有手填预热 TLB。目录用层级路径表展示，没有复刻 ASCII 树形排版。
- LFU 统计驻留期间频次，同频按最早装入淘汰；随机算法固定种子；SCAN/C-SCAN 需要反向服务时走边界，所有请求完成后停止；循环回程计入移动量。
- 没有声称所有输入与原网页逐像素、逐事件等价。完成度基于上述功能清单及实际可运行验收，C/C++ 练习不抵扣原功能缺项。

## 推送前静态审查与修复

2026-10-12，在类型检查之外人工审阅参数解析、算法快照、React 状态、Worker 生命周期、草稿保存与构建集成，修复如下：

- 清空 CPU 时间片时，模拟器此前套用默认值而代码样例生成报错，可能触发整块页面错误；现统一拒绝空输入并保留旧结果。
- 普通页表实验此前也更新 TLB，重复访问会误显示“TLB 命中”；现仅 TLB 实验使用缓存。
- 哲学家已持左叉时不能取得空闲右叉；现允许保留自身持有的叉，并仍阻止重复进餐或争用其他人的叉。
- PID 1 退出可产生没有有效回收者的进程状态；现明确作为常驻回收进程，并补测孤儿收养、wait 唤醒与回收。
- 参数修改后旧算法对比仍可能显示；现清除旧对比。模拟参数更新而代码 stdin 未同步时显示提示。
- 本机存储失败时不再声称“草稿已保存”；空字符串草稿也可正确恢复。编辑器 Shift+Tab 允许离开输入框，插入缩进遵守源码上限。
- 样例对负页号、越界磁盘柱面、非正内存请求增加检查；磁盘图沿用统一参数解析，防止可接受的分隔符输入造成 NaN 坐标。
- 自动回放不再从状态更新函数内嵌更新其他状态；Worker 构造异常可见，保留已有运行时异常与超时处理。

新增回归覆盖上述模型、UI 和样例问题。脚本语法检查及 git diff --check 通过。额外使用 --file 模式从生产 index.html 直接加载，验证与打包桌面版一致的本地文件 Worker 场景。

测试通过表示本次审查和验证范围内没有已知阻塞问题，不是对所有任意 C/C++ 程序或原应用全部功能作绝对无 bug 保证。
