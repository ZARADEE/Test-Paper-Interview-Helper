# 学习闭环与 Agent 组卷

兼容修复（2026-10-09）：408 模板写入改为显式数据库列名，兼容历史迁移后的字段顺序。启动时仅识别并恢复早期版本错位写入的六个预设，不覆盖正常模板。408 题目在导入、审核及重启时保留自己的学科标签。新增真实数据库页面回归脚本 `frontend/integration-probe.cjs` 和旧表结构回归测试。

## 使用入口

1. 系统默认内置 408 综合模拟卷，与考研政治标准卷并列。点击「试卷模板」顶部横栏的「增加 408 模板套件」，才会加入四科选择题训练和四个专项模板。重复添加不会覆盖已修改模板。选择题四科题量为 11 / 11 / 10 / 8；综合卷 150 分、180 分钟，综合题结构是可编辑的练习配置，不承诺对应某年真题。
2. 经用户确认授权，已内置参考项目的 1,576 道选择题（数据结构 411、组成原理 373、操作系统 417、计算机网络 375）及 1,641 张题目和解析图片。无需 API Key 即可刷题。另已补齐知识图谱内 87 处简答练习，去重为 48 道（操作系统 40、数据结构 1、组成原理 7），保留全部章节关联和一张答案原图。参考数据没有标准综合大题，150 分综合卷仍需补充大题后才能完整组卷。题目没有原始难度分级，导入统一设为中等，可在系统内调整。
3. 模板可编辑题型、题量、分值、标签、难度、单/多选模式和科目占比。保存和组卷共用后端约束；校验按钮先保存当前编辑再检查。
4. 「使用 Agent 组卷」默认关闭。打开立即弹出连接窗口，填写 HTTPS API 基础地址（包含 `/v1` 等版本路径）、模型名称、API Key 和可选组卷要求。取消不会打开开关，确认后需保存模板。
5. 到「考研组卷」选择模板。关闭 Agent 使用本地规则；开启使用兼容 Chat Completions 的模型服务。重启应用后会重新要求填写 Key。

## Agent 边界

- Agent 从已审核候选题 ID 中规划各分区，不生成虚构题目。候选池每分区最多 `max(120, 3 × 题量)` 道。
- 发给模型的是候选 ID、标签、知识点、章节、难度、结构约束和用户组卷要求，不发送题目答案、个人笔记或学习记录。
- API Key 只在前端模块内存及本次后端请求中使用，不保存到模板、数据库或浏览器存储。服务费用由配置的提供商收取。
- 后端拒绝非 HTTPS、内网地址及重定向；设有连接超时和响应大小上限。错误消息不会原样转发提供商响应或请求凭据。
- 校验分区、题数、跨分区去重、题库范围、锁定 ID 和占比。不通过则报错，不偷偷退回本地规则；库存不足在调用模型前报错。
- 本地固定种子可复现选题，Agent 的输出不保证跨调用一致。

## 学习功能

知识地图和学习记录仪面板按用户要求暂时移除，保留已有练习数据。

练习提供计时、答题卡跳转、题目标记、未提交选项暂存、刷新恢复及最近 50 组历史。已提交题目可复盘，不重复提交。答案后可记录错因自评、笔记、收藏，按关联知识点开始专项训练。

练习可以导出题卷 PDF；完成整组后可以导出答案解析 PDF。原有错题 PDF、组卷 PDF/DOCX 继续可用，并支持无原图时导出文本题干和选项。

## 全量核验

408 共 1,624 道不重复题目：1,576 道选择题和 48 道简答题。简答题作为独立题型，可在模板分区中选择并组卷、预览和导出；小题狂练仍只自动判选择题。原始答案按原样保存，其中少数简答答案存在源数据错配，导入不表示已校订答案。默认综合卷不会把知识点简答题当综合大题抽取。

逐题文本、所有原始选择题图片像素、数据库内容与 87 处简答来源映射通过 scripts/audit_zhijing408.py 校验；结果见 zhijing408-audit.json。
